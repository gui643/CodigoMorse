# Codigo Morse com árvore binária
Integrantes: Guilherme Vicentin de Paiva Monteiro, Arom Pietro Coronil e Kaue Paulin Carneiro
Grupo: TDE2 10

Projeto implementado em java que desenvolve um código morse utilizando uma árvore binária.
Na árvore, o filho a esquerda será utilizado para representar o ".", enquanto a direita 
será representado usando "-". O projeto usa console gráfico para exibir opções de decodificação e 
codificação, além disso a codificação e decodificação de arquivos txt.

# Funcionamento 

Código morse
1. Codificar texto digitado
2. Decodificar Morse digitado
3. Codificar arquivo de texto
4. Decodificar arquivo Morse
5. Mostrar árvore
6. Encerrar

# 1. Codificar texto digitado
Selecione a opção 1 e digite o texto desejado (de A-Z sem acento, 0-9 e espaços).
O programa mostra o código Morse correspondente. Cada espaço entre palavras vira uma barra (`/`).

# 2. Decodificar Morse digitado
Selecione a opção 2 e digite o Morse em uma única linha, usando apenas ponto (`.`), traço (`-`), barra (`/`) e espaço.
As letras são separadas por espaço e as palavras por barra.

# 3.Codificar arquivo de texto
Selecione a opção 3 e informe o caminho de um arquivo `.txt` com texto comum. O programa mostra o Morse correspondente.

# 4.Decodificar arquivo Morse
Selecione a opção 4 e informe o caminho de um arquivo `.txt` com uma única linha em Morse, no formato da opção 2.
O programa mostra o texto correspondente.

# 5.Mostrar árvore
Selecione a opção 5 para ver a árvore Morse no console. A raiz aparece como RAIZ, "." indica o filho da esquerda 
e "-" indica o filho da direita.

# 6.Encerrar o programa
Para encerrar, selecione a opção 0.
